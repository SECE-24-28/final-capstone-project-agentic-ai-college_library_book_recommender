# AI-Powered College Library Book Recommender

## Project Overview

The AI-Powered College Library Book Recommender is a browser-based recommendation system that helps students discover relevant books based on topics, book titles, authors, or ISBN numbers.

The current version uses a 1,000-row college-focused CSV dataset with rich metadata, explainable ranking, ISBN lookup through free public APIs, and borrow/return tracking persisted back to the dataset.

---

# Project Objective

To build an intelligent library assistant that:

* Understands natural language search queries
* Recommends relevant books from a college-focused library dataset
* Explains why each book matches the user's interest
* Supports ISBN-based book lookup
* Shows availability, shelf location, and borrow status
* Supports borrow and return updates persisted to CSV

# Key Features

## 1. Semantic Search

Users can search naturally:

Examples:

* Artificial Intelligence
* Machine Learning
* Java Programming
* Data Structures
* Ancient History

The system understands meaning rather than exact keyword matching and also boosts exact category or author matches.

---

## 2. Hybrid Recommendation Engine

Recommendations are ranked using:

Final Score =
0.5 × Semantic Similarity
+
0.2 × Category Match
+
0.15 × Author Similarity
+
0.15 × Popularity Score

This improves recommendation quality beyond simple similarity search.

---

## 3. Explainable AI

For every recommendation, the system generates:

* Why the book matches the query
* Main topics covered
* Difficulty level
* Recommended audience

Example:

Why This Book Matches

You searched for "Java Programming".

This book focuses on object-oriented programming, Java fundamentals, classes, inheritance, exception handling, and software development principles. It is highly relevant because Java is the primary topic covered throughout the book.

Difficulty Level:
Beginner

Recommended For:

* Students
* Java Learners
* Placement Preparation

# Project Workflow

Step 1

User enters:

* Book title
  OR
* Topic
  OR
* ISBN

Step 2

The query is compared against the dataset using hybrid scoring.

Step 3

Cosine similarity is calculated between the query embedding and all stored book embeddings.

Step 4

Hybrid ranking combines:

* Semantic similarity
* Category relevance
* Popularity score

Step 5

Top recommendations are selected.

Step 6

Groq LLM generates human-readable explanations.

Step 7

Results are displayed to the user.

# AI Concepts Used

## Natural Language Processing

Converts text into machine-understandable representations.

## Semantic Embeddings

Represents books and queries as vectors in high-dimensional space.

## Vector Search

Finds books with meanings similar to the user's query.

## Cosine Similarity

Measures semantic closeness between vectors.

## Explainable AI

Provides reasoning behind recommendations.

## Retrieval-Augmented Generation (RAG-style Workflow)

Retrieval:
Book recommendations from dataset

Generation:
Explanations generated by Groq LLM
